# Adelaide Carpentry 本地内容后台方案

## 目标与已确认范围

用户于 2026-10-19 确认复用 Perth Handymate 本地后台的界面和操作方式。桌面双击即可打开，支持中文页面筛选、点选预览文字编辑、磁盘草稿、英文对照及历史恢复。不改线上网站，不自动发布。

## 实现选择

采用既有后台代码适配，不另建 CMS 或数据库。复用 `E:/Ellis-Services/Perth Handymate/source/editor/ui` 与 `tools/editor` 的界面、草稿与同源安全设计；不修改 Perth Handymate，不复制该站品牌事实、客户数据或草稿。新建后台属于本站的独立本地子系统。

从零开发完整 CMS 会更慢；仅使用浏览器存储不能可靠保留草稿，因此不采用这两种方案。

## 页面及数据适配

- 本站唯一源码目录：`E:/Ellis-Services/Adelaide Carpentry Hub/source`。
- 保留本站 `build.mjs`、`src/content-pack`、`src/i18n` 为正式内容来源。
- 后台启动检查源码指纹；必要时运行现有 `npm run build`，从 `public` 下的英文及 `/zh/` 中文配对页面建立可编辑字段。
- 用相同 DOM 遍历规则逐字段核对中英文；结构不一致时拒绝编辑该页并给出明确提示，不能按索引错配。
- 48 对常规页面可筛选；双语 404 可作为额外页面收录。页面清单不读取旧目录或线上版本。
- 正文、标题、问答、按钮文字、图注、图片替代文字和 SEO 文案可编辑中文；英文原文只读对照。共享导航、完整页尾、号码、邮箱、地址、价格、公司与保险事实锁定。
- 图片文件及链接目标暂不提供编辑，延续参考后台的行为，避免扩大首版范围。

## 保存与中英同步边界

- 点击保存仅写入 `.local-editor/drafts` 的真实磁盘草稿及历史；不得只保存在浏览器。
- 保存后刷新预览，退出重开可继续；恢复历史会新增修订，不删除历史。
- 页面与草稿均带基线哈希和修订号；源码变化或并发保存冲突必须阻止覆盖并保留输入。
- 明确显示“草稿已保存／待同步英文／未发布”。不声称保存即改动正式源码。
- 提供 `npm run editor:changes` 导出修改对照，供当前助手按精确修订同步英文、更新本站原始内容所有者及译文，再运行双语构建与测试。
- 首版不接入自动翻译，不发送内容到第三方，不自动推送 GitHub 或部署 Vercel。后续发布仍须用户当次授权。

## 本地运行与桌面入口

- 后台只监听 `127.0.0.1`，首选端口 4212，冲突时在有限范围递增；不接管其他站端口。
- 桌面快捷方式名称为“Adelaide Carpentry 本地后台”，启动时隐藏终端并打开默认浏览器后台页面。
- 多次双击复用属于本站的健康实例；不因端口已占用误认其他后台。
- 启动失败保留本地日志，并显示可操作提示；不下载未识别软件或引入在线服务。

## 安全与站点隔离

- 复用 Host／Origin 校验、会话令牌、JSON 请求体限制、路径归属验证及原子草稿写入。
- 编辑预览移除跟踪脚本与 iframe，禁止表单提交和访客交互，不发送真实咨询。
- `.local-editor` 加入忽略规则；后台源码和草稿不进入公开 `public`，不更改现有线上 API。
- 保留现有未跟踪旧散列资源，绝不清空用户草稿或用其他站资料覆盖本站。

## 验收标准

1. 桌面双击可打开正确品牌后台，重复启动不会创建重复服务。
2. 页面搜索、中文文字点选、SEO 字段、英文对照、桌面／手机预览均可使用。
3. 用隔离测试草稿验证保存、重新读取、历史恢复、并发冲突、源码基线变化、空值与超长输入拒绝。
4. 验证外源请求、错误 Host、路径穿越及表单提交被拒绝，敏感业务字段不可编辑。
5. 本站配对页面字段完整可读取；构建、既有完整性检查和新增后台测试通过。
6. 检查公开构建没有后台或草稿；记录本地入口和最短操作步骤。没有发布操作。
